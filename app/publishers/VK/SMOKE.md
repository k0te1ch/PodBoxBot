# VK Donut: доступ и смоук

Основной режим `VK_MEDIA=podcast`: послешоу уходит эпизодом в раздел
подкастов сообщества (`vk.ru/podcasts-<id>`) с доступом «Только донам» и
публикуется постом на стене. У официального API нет загрузки подкастов,
поэтому publisher повторяет запросы страницы подкастов по сессии браузера.
Запросы сверены с записью ручной публикации (обычный выпуск и послешоу):

1. `al_podcasts.php` `a_add_box`: окно «Добавить эпизод», адрес загрузки mp3;
2. загрузка mp3 на `pu.vk.ru/gu/audio/v2/upload`;
3. `al_audio.php` `done_add`: эпизод из загруженного файла;
4. `al_podcasts.php` `a_edit`: название, описание, обложка из галереи
   подкаста и `privacy=2` (только донам; `0` — всем);
5. `login.vk.ru/?act=web_token` и `wall.post` с вложением `podcast-<id>_<n>`.

Замок стоит на эпизоде: пост на стене виден всем, а слушать эпизод могут
только доны. Внутренние запросы VK может поменять; тогда ошибка придёт
админу в бот, а запасные режимы ниже работают через официальный API.

Запасные режимы (`VK_MEDIA`), официальный VK API и токен `VK_ACCESS_TOKEN`:

- `video`: mp3 склеивается с обложкой `VK_COVER_PATH` в mp4 и загружается в
  видеозаписи сообщества. Если раздел «Видео» открыт, запись видна и не
  донам: закройте раздел или сделайте его доступным только администраторам;
- `doc`: mp3 документом (скачивается, плеера нет);
- `none`: только текст.

Замок в этих режимах: `donut_paid_duration` в `wall.post`
(`VK_DONUT_PAID_DURATION=-1` — навсегда только для донов, число — через
сколько дней пост откроется всем).

## Что нужно от владельца

1. VK Donut подключён в сообществе, раздел подкастов включён.
2. Режим `podcast`: аккаунт администратора сообщества, вход на vk.ru в
   браузере. Заголовок `Cookie` любого запроса к `vk.ru` (DevTools →
   Network → запрос → Request Headers) и User-Agent:

   ```sh
   docker compose run --rm publisher_vk python smoke.py import-cookie
   ```

   Сессия ложится в `secrets/vk/vk_session.json`. Она равносильна входу в
   аккаунт: не пересылайте её и не коммитьте. Выход из аккаунта в браузере
   или смена пароля её сбрасывают, тогда команду повторить.
3. В `.env`: `VK_GROUP_ID` (число без минуса), при необходимости
   `VK_PODCAST_PRIVACY` и `VK_PODCAST_COVER_ID` (id обложки из галереи
   подкаста вида `-<group>_<id>`, пусто — первая в галерее).
4. Только для запасных режимов: standalone-приложение на dev.vk.com и
   пользовательский токен админа с правами `wall,video,docs,offline` в
   `VK_ACCESS_TOKEN`.

## Проверка

```sh
docker compose run --rm publisher_vk python smoke.py check
docker compose run --rm -v "$PWD/test.mp3:/app/files/test.mp3" \
  publisher_vk python smoke.py publish --mp3 /app/files/test.mp3 --yes
```

`check` в режиме `podcast` получает токен веб-приложения и открывает окно
добавления эпизода, ничего не публикуя. Пост и эпизод увидят доны: удалите
их после проверки. После успешного прогона включите кнопку в боте:
`VK_ENABLED=true`.

Сброшенная сессия (вместо ответа пришла страница входа, login.vk.ru не выдал
токен) и ошибки авторизации API (коды 5, 7, 15, 27, 200, 214…) приходят
админу в бот с подсказкой и не повторяются.
