# VK Donut: доступ и смоук

Интеграция — официальный VK API. Раздел аудио закрыт для сторонних
приложений, а загрузка через внутренние запросы vk.com ломалась раз в месяц
(VK меняет хэши), поэтому звук уходит одним из официальных способов
(`VK_MEDIA`):

- `video` (по умолчанию) — mp3 склеивается с обложкой `VK_COVER_PATH` в mp4
  и загружается в видеозаписи сообщества, в посте играет плеер. Само видео
  лежит в разделе «Видео» сообщества: если раздел открыт, запись видна и не
  донам — закройте раздел или сделайте его доступным только администраторам;
- `doc` — mp3 документом (скачивается, плеера нет; VK может не принять mp3
  как документ — проверяется смоуком);
- `none` — только текст.

Замок — `donut_paid_duration` в `wall.post`: `VK_DONUT_PAID_DURATION=-1` —
пост навсегда только для донов, число — через сколько дней он откроется всем.

## Что нужно от владельца

1. VK Donut подключён в сообществе.
2. Standalone-приложение на dev.vk.com (VK ID) и пользовательский токен
   админа сообщества с правами `wall,video,docs,offline`. С `offline` токен не
   истекает, пока не сменён пароль и не отозван доступ приложения.
3. В `.env`: `VK_ACCESS_TOKEN`, `VK_GROUP_ID` (число без минуса),
   при необходимости `VK_MEDIA`, `VK_DONUT_PAID_DURATION`.

## Проверка

```sh
docker compose run --rm publisher_vk python smoke.py check
docker compose run --rm -v "$PWD/test.mp3:/app/files/test.mp3" \
  publisher_vk python smoke.py publish --mp3 /app/files/test.mp3 --yes
```

Пост увидят доны — удалите его после проверки. После успешного прогона
включите кнопку в боте: `VK_ENABLED=true`.

Ошибка авторизации (коды VK 5, 7, 15, 27, 200, 214…) приходит админу в бот с
подсказкой про токен и не повторяется.
